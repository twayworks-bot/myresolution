# 말씀 나눔 매거진 웹앱 (Grace & Fellowship Magazine)

주일 설교 나눔지(`20260913.txt` 등)를 기반으로 성도들이 모바일 기기에서 말씀을 묵상하고, 소그룹에서 깊이 있는 나눔을 나눌 수 있도록 돕는 **모바일 반응형 매거진 웹 애플리케이션**입니다.

---

## 1. 프로젝트 목적 (Purpose)

- **디지털 나눔지 혁신**: 텍스트 파일이나 종이 인쇄물 형태의 설교 나눔지를 시각적이고 직관적인 모바일 매거진 카드로 재구성합니다.
- **소그룹 나눔 편의성 극대화**: 아코디언 UI를 통해 나눔 질문과 복음적 결단을 한눈에 파악하고, 해설과 묵상 질문을 차례대로 열어보며 원활한 소그룹 모임을 진행할 수 있도록 지원합니다.
- **간편한 운영 및 관리**: 나눔지 텍스트를 복사하여 붙여넣기만 하면, 정규표현식 파서가 자동으로 항목을 분류하여 즉시 새로운 나눔 카드로 생성·저장할 수 있도록 합니다.
- **차분한 묵상 환경 제공**: 성도들이 말씀과 결단에 집중할 수 있도록 감성적인 정적 배경 이미지, 에세이 컬럼 타이포그래피, 딥블루/베이지 묵상 톤앤매너를 제공합니다.

---

## 2. 프로젝트 설명 (Description)

본 웹앱은 가볍고 빠른 **Python FastAPI** 백엔드와 **SQLite3** 데이터베이스, 그리고 별도의 번들링/빌드 없이 즉시 구동되는 **모바일 반응형 Single Page Application (SPA)** 프론트엔드로 구성되어 있습니다.

성도들은 스마트폰, 태블릿, PC 어디서든 브라우저를 통해 접속할 수 있으며, 기기 화면의 폭과 높이에 맞추어 최적화된 레이아웃으로 말씀을 묵상할 수 있습니다.

---

## 3. 주요 구현 내용 (Implementation Details)

### 1) UI/UX & 디자인 요소
- **감성적인 정적 배경 이미지**: 아침 햇살이 비치는 성전 창가 배경(`static/assets/bg.jpg`)과 은은한 프로스티드 글래스 오버레이로 깊이 있는 묵상 분위기 연출.
- **참고 성경말씀 인용구 박스**: 앰버/골드 좌측 보더 강조선, `참고 성경말씀 본문` 뱃지, 이탤릭 세리프 서체의 인용구(Blockquote) 박스로 일반 해설과 뚜렷하게 구별.
- **에세이 컬럼 타이포그래피**: 고품격 신앙 에세이 칼럼을 읽듯 Noto Serif KR 및 Pretendard 폰트 믹스, 1.85배의 넉넉한 줄간격, 챕터 인디케이터 적용.
- **복음적 결단 톤앤매너**:
  - **딥블루 테마 (기본값)**: 깊은 밤하늘/기도실 분위기의 딥 네이비 배경 + 골드 텍스트 + 🕊️ 비둘기 아이콘.
  - **은은한 베이지 테마**: 상단 버튼 클릭 시 온화하고 평온한 베이지 톤으로 원터치 전환 가능.
- **나눔 질문 아코디언 컴포넌트**:
  - **헤더 (닫힌 상태)**: 나눔 번호/제목 및 **복음적 결단 기도문 상시 노출**.
  - **바디 (펼친 상태)**: 상세 말씀 해설 및 1, 2, 3번으로 정돈된 소그룹 묵상 질문 목록 표시.
  - 상단 컨트롤: **모두 펼치기 / 접기** 토글 및 시니어 성도를 위한 **글자 크기 확대(가+) / 축소(가-)** 버튼.

### 2) 백엔드 & 스마트 텍스트 파서
- **정규식 기반 자동 파서 (`parser.py`)**: 나눔지 원문에서 아래 항목들을 100% 자동 분리 추출:
  - 말씀 일정, 설교 시리즈, 제목, 부제, 성경구절 및 본문, 설교 핵심 요약, 핵심 메시지, 7개(혹은 그 이상)의 나눔 질문, 세부 해설, 묵상 질문(리스트), 복음적 결단.
- **SQLite 관계형 데이터베이스 (`database.py`)**:
  - `sermon_cards`: 설교 본문 및 요약 등 메타데이터 관리.
  - `discussion_topics`: 나눔 질문별 해설, 묵상 질문, 복음적 결단 데이터 관리 (`ON DELETE CASCADE` 연동).
- **FastAPI REST API (`app.py`)**:
  - `GET /api/cards`: 전체 나눔 카드 목록 조회.
  - `GET /api/cards/{id}`: 세부 나눔 내용 및 질문 목록 조회.
  - `POST /api/cards/parse`: 붙여넣은 텍스트 자동 파싱 및 JSON 프리뷰 반환.
  - `POST /api/cards`: 새 카드 및 질문 목록 DB 저장.
  - `DELETE /api/cards/{id}`: 나눔 카드 삭제.
  - `GET /api/sample`: `20260913.txt` 샘플 텍스트 제공.

### 3) 관리자 기능 (우측 하단 FAB)
- 화면 우측 하단에 고정된 연필 모양의 플로팅 액션 버튼(FAB) 배치.
- 텍스트 붙여넣기 및 **[20260913.txt 샘플 불러오기]** 지원.
- 분석 후 입력 폼을 통해 제목, 일정, 요약, 결단 등을 직접 검토/수정한 후 저장 가능.
- 기존 발행된 나눔 카드 삭제 및 목록 관리 탭 제공.

## 5. 실행 및 사용 방법 (Usage Guide)

### 1) 원클릭 실행
프로젝트 루트 폴더에 있는 **`run.bat`** 파일을 더블 클릭하면 필요한 패키지 확인 및 서버 실행이 자동으로 이루어집니다.

### 2) 터미널 직접 실행
```powershell
# 가상환경 활성화 후 실행
.\.venv\Scripts\activate
python -m uvicorn app:app --host 0.0.0.0 --port 8000 --reload
```

### 3) 웹앱 접속
웹 브라우저(크롬, 사파리, 엣지 등)를 열고 다음 주소로 접속합니다:
👉 **`http://127.0.0.1:8000`**

### 4) 화면 사용법
1. **메인 화면 (매거진 피드)**:
   - 발행된 설교 카드가 매거진 형태로 정렬되어 있습니다.
   - 카드를 터치/클릭하면 세부 나눔 화면으로 이동합니다.
2. **세부 나눔 화면**:
   - 상단에서 본문 성경구절 인용구, 설교 요약, 핵심 메시지를 에세이 칼럼 형태로 묵상합니다.
   - 아래의 나눔 질문 목록에서 **질문과 복음적 결단 기도문**을 바로 확인합니다.
   - 질문 카드를 터치하면 **세부 말씀 해설**과 **소그룹 묵상 질문(1, 2, 3번)**이 펼쳐집니다.
   - 우측 상단의 `가+ / 가-` 버튼으로 글자 크기를 조절하거나, `🌙 / 🌾` 버튼으로 결단 카드 톤을 딥블루/베이지로 변경할 수 있습니다.
3. **관리자 화면**:
   - 우측 하단 원형 관리 아이콘(✏️)을 클릭합니다.
   - 나눔지 원문을 붙여넣거나 `20260913.txt 샘플 불러오기`를 클릭한 후, `스마트 자동 분석 & 미리보기`를 누릅니다.
   - 자동 분류된 내용을 검토하고 `이 내용으로 나눔 매거진 카드 생성하기`를 누르면 즉시 새 카드가 발행됩니다.

## 6. Docker 컨테이너 실행 가이드 (Docker Guide)

### 1) 이미지 빌드
```bash
docker build -t myresolution-app:latest .
```

### 2) 컨테이너 실행 (기본 설정: prefix=myresolution, port=5000, 볼륨 연동)
```bash
docker run -d \
  --name myresolution \
  -p 5000:5000 \
  -v myresolution_data:/app/data \
  -e DEFAULT_PREFIX=myresolution \
  myresolution-app:latest
```

- **웹 브라우저 접속**:
  - 기본 Base URL: `http://localhost:5000/myresolution/` (루트 `http://localhost:5000/` 접속 시 자동 리다이렉트)
  - 헬스체크 API: `http://localhost:5000/myresolution/api/status`
- **데이터 영구 보존(Persistent Volume)**:
  - SQLite DB 파일이 볼륨 경로(`/app/data/sermon_sharing.db`)에 영구 저장됩니다.
- **Prefix 변경 실행 (예: 루트 또는 다른 서브경로)**:
  - 루트 경로로 서비스 시: `-e DEFAULT_PREFIX=""`
  - 다른 prefix 사용 시: `-e DEFAULT_PREFIX="sermon"`
